# OIBSIP — Oasis Infobyte Python Programming

This repository contains selected Python projects for the Oasis Infobyte Python Programming internship. The Task List asks interns to complete at least three of the five Python tasks.

## Projects

- **Task 2 — BMI Calculator:** calculates BMI from weight and height, then reports the matching category. Includes source code, instructions, and a sample run transcript.
- **Task 3 — Random Password Generator:** creates passwords using the character groups selected by the user. Includes source code, instructions, and a transcript with the generated password redacted.
- **Task 4 — Basic Weather App:** looks up current weather for a city or postal code. Includes source code, setup instructions, and a genuine run transcript. Weather values change over time.

Each project folder has its own README with setup and run instructions. Open the folder for the task you want to use.
